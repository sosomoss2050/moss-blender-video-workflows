# 镜头拆解表模板（Recreate · 分析型）

用途：复刻参考视频时，逐镜头拆解原片的可观察事实，作为白模复刻与生成对照的依据。与原创用的 [`shot-list.md`](../moss-blender-video-original/templates/shot-list.md) 不同，本表**强调区分「观察到的事实」与「遮挡区域的估计」**。

工作流约定：拆解前先探测原片实际时长/帧率/尺寸；原片多镜头且用户未指定时，按原片镜头结构处理。

## 填写要点

1. **时间范围逐镜头连续无缝**；先按原片实际切点记录，不自行平均。
2. **构图 / 主体比例**：用"主体占画幅高/宽比例"量化，便于白模比对。
3. **空间/道具布局**：记录地面、墙体、设备/道具位置与人物走位方向。
4. **相机运动**：固定 / 推 / 拉 / 摇 / 跟移 / 升降 / 环绕，附速度感觉。
5. **事实 vs 估计**：被遮挡或看不清的结构标为"估计"，**不得当作事实**；单目视频无法唯一恢复深度，隐藏结构只搭够支撑画面的简模。
6. **比对断点**：拆解完先用白模关键帧与原片关键时刻并排对比（见 `comparison.md`），偏差先修构图与时序，再进生成。
7. **不要用"风格不同"掩盖构图或时序错误**——风格是后一步，空间与节奏必须先对上。
