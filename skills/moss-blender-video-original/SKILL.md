# 原创白模视频工作流

从文字创意建立原创空间、动作和镜头，完成可编辑白模动画、生成提示词及视频模型成片。用户给了必须复刻的视频时使用复刻工作流；只有氛围参考图时仍可在本流程原创。

## 开始
提取题材、人物数量、动作、时长、画幅、输出规格及最终风格。用户要求全自动时用合理默认值推进：8 秒、1080p、24fps、单一连续镜头、纯白简模、无贴图、简单照明。已给定的参数始终优先，不把默认科幻剧情强加到其他题材。
先检查 Blender、控制接口及视频服务可用性；缺失后半段服务不妨碍先完成白模与提示词，但必须报告缺口。运行模型由宿主决定，不声称 skill 自动启用了 GPT6 Astra。

## 执行
0. **项目目录初始化（硬性第一步）**：在开始任何制作前，先建立并进入项目工作目录：
   ```bash
   mkdir -p ~/workspace-<agent>/projects/<项目名>/{tmp,outputs,refs}
   cd ~/workspace-<agent>/projects/<项目名>
   ```
   - 后续所有操作（Blender 导出、libtv 命令、ffmpeg 编码）**必须在此目录内执行**，禁止在别处散落产物。
   - 中间产物（原始下载、压缩副本、prompt/json、白模工程中间帧）放 `tmp/`（英文文件名）；最终交付成品放 `outputs/`。
   - `MEDIA:` 投递只投 `outputs/` 内的绝对路径（顶格、独占一行、回复最后一行），发出后自查 `ls -lat ~/.openclaw/media/outbound/` 确认进入队列。
   - 收尾：投递确认成功后，按文件名前缀精确清理本次 `tmp/` 中间文件（禁止 `rm -rf tmp/` 全目录）；`outputs/` 成品保留。
1. 输出 shot-plan.md：创意一句话、场景布局、分秒动作、镜头路径、触发事件、结尾状态。动作数量必须适合时长；将原因安排在结果之前，并留出站稳和动作过渡时间。常规创意选择直接完成，不增加逐阶段审批。
   - **镜头表模板**：[templates/shot-list.md](templates/shot-list.md)（逐镜头景别/时长/运镜/在场角色/声音）。
   - **先给用户确认镜头表，再动手搭白模/生成参考图**，避免方向不符白做工。
2. 生成统一风格的角色与场景参考图：
   - **角色定妆照模板**：[templates/character-lock.md](templates/character-lock.md)（Seedream 4.5，擅多角色一致性与中式风格）。
   - 一位角色一张图，**生成好立即附图给用户确认，通过后再生成下一位**；全组统一风格。
   - 多镜头时，各角色/场景参考图需**在建 video 节点前全部备齐**。
3. 阅读 [Blender 制作与验收](references/blender-production.md)。先搭地面、墙体、入口、主要设备和人物占位体，检查通行宽度、相机可见性和手可触及范围，再做人物关节与动画。
4. 先调根节点行走与停步，再添加对侧摆臂、抬手与装置反馈，最后调整相机。若行走与交互手势重叠，分离控制并平滑混合，避免抬手破坏整个步态。
5. 做完整低成本预览，检查相位、脚底滑动、穿模、手部接触、镜头抖动及末尾稳定状态。修复后再正式渲染和编码，保存可编辑工程及验收记录。
6. 阅读 [视频生成](references/video-generation.md)，将白模动作时间线写入提示词，补充最终外观，并通过可用且获授权的视频模型生成新视频。本机可用 libtv CLI 时改走 [libtv 交付路径](references/libtv-delivery.md)，白模关键帧挂参考图、经 libtv 画布生成。
   - **多镜头同场景优先一次提交**（单节点多镜头硬切）：用 [templates/storyboard-7seg.md](templates/storyboard-7seg.md) 写 `【Storyboard】` 段，挂齐全部角色/场景参考图。
7. 检查最终视频与白模的动作和镜头一致性，再分别交付。只完成白模时不得把它称为模型生成的最终成片。

## 8 秒实验舱示例
仅当需求与此相符时采用：0–0.5 秒入口建立；0.5–3.8 秒走近设备；3.8–4.5 秒减速站稳；4.5–5.5 秒抬手触发；5.5–7.5 秒中央装置蓝光渐亮；7.5–8 秒镜头与主体保持。动作时间可按步幅、距离调整，不能靠滑动人物硬凑时长。

## 执行边界
全自动意味着在已授权范围内完成制作、预览、修复和导出，不意味着忽略不可用工具或重复付费生成。不要求用户手动操作 Blender；需要补充关键输入或权限时说明具体缺口。用户只要求其中某阶段时按该范围交付。
