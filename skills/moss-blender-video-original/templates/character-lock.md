# 角色参考图模板（Character Lock · 定妆照）

用途：在视频生成前，用 LibTV 的图片模型（Seedream 4.5，擅长多角色一致性与中式风格）先生成统一风格的角色定妆照，再作参考图挂到 video 节点，锁定角色形象。

工作流约定（2026-10-11 验证）：
- **一位角色一张图，生成后立即附图给用户确认，通过后再生成下一位**。
- **全组角色统一风格**（同一世界观、同一光影与调色）。
- 输出 2K；人物定妆照用竖构图 `ratio=3:4`；场景空镜用 `ratio=16:9`。

---

## 模板

```text
<风格基调>：<画面质感>，<时代审美>，电影级调色，<光线>，浅景深，细腻皮肤质感，35mm 电影镜头，4K超清。
人物定妆照：一位约<年龄>的<身份>（<主角/配角定位>），面容<面容>，眉目<神情>，<眼神>;
<发型与发饰描述>;
身着<颜色>与<颜色>相间的<朝代>风格<款式>，<衣料质感与纹样>;
<体态>，<站姿与手部动作>;
<整体气质>。
背景：虚化的<场景>，<关键环境元素>，<光色>。
整体氛围：<氛围词>。
统一世界观设定：<朝代/题材>，与其余角色及场景参考图同一世界观、同一光影与调色风格。
禁止：无现代元素，无水印，无文字，无浓艳妆容，无夸张特效。
```

---

## 填写要点

1. **风格基调段必须全组一致**（第一句逐字复用），这是"统一风格"的关键；末句"统一世界观设定"也逐字复用，并点名与其余参考图同源。
2. **面容/发型/服饰/体态/气质**五项写具体：年龄段、脸型气质、发式、颜色与款式、站姿。含糊描述会导致形象漂移。
3. **背景虚化**处理（浅景深），既能带出场景信息，又不抢主体。
4. 人物图用 **`-s ratio=3:4 -s quality=2K`**；场景空镜用 **`-s ratio=16:9`**。
5. **禁止项**固定带上"无现代元素、无水印、无文字、无浓艳妆容"。
6. 生成后**先给用户确认再继续**；不满意时按用户指出的方向（脸型/颜色/年龄）改 prompt 重跑，不要盲改多项。
7. 命令：`libtv node --x <x> --y <y> create "参考图-<角色名>" -t image -s "model=Seedream 4.5" -s ratio=3:4 -s quality=2K --prompt "<上面模板>" --run`；再从返回的 `data.url[0]` 下载。
