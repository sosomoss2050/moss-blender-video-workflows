# 镜头表模板（Shot List）

用途：分镜规划的第一步产物 `shot-plan.md` 的核心表格，逐镜头锁定景别、时长、运镜、内容与声音。既用于原创创意，也作为单节点多镜头 prompt 的数据来源（填进 [`storyboard-7seg`](storyboard-7seg.md)）。

工作流约定：**先出镜头表给用户确认，再动手搭白模/生成参考图**，避免方向不符白做工。

## 填写要点

1. **时长逐镜头指定，不必平均**。先按内容需要分配，再核对总和是否落在模型允许区间（Seedance 2.5 为 4–30s）。
2. **每个 Shot 一行**，起止秒连续无缝（前一段止 = 后一段起）。
3. **在场角色列必填**：列出该镜头画面中**所有**应在场的角色，即使不是主体。这是防穿帮的依据（见 `storyboard-7seg.md` 的【角色在场表】）。
4. **景别**用标准词：大远景 / 全景 / 中景 / 中近景 / 特写 / 大特写。
5. **运镜**写清方式与速度：固定 / 极缓慢推镜 / 平稳跟移 / 轻微升降 / 缓慢拉远 / 环绕。
6. **对白/声音**：有台词的写`角色（语气）：「台词」`；否则写环境音或"无台词，仅氛围"。
7. **单镜头内部的时序**（如"0s 空镜→1s 入画"）写在"画面内容"里；这是模型能听懂的**镜头内**时间线，与 `[Shot]` 级硬切是两回事。
8. 镜头表确认后：
   - **原创**：据此搭白模 → 生成参考图 → 汇总成 `storyboard-7seg` prompt 一次提交。
   - 时长与运镜即为白模预演和最终生成的依据，三者须一致。
